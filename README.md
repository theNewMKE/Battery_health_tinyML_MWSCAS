# Battery health tinyML published on MWSCAS 2024.
Code and details for predicting li-ion battery health on Arduino BLE 33.
This is a published work on Midwest Symposium on Circuits and Systems (MWSCAS) conference in 2024 summer. 
A continuous journal version of this work will be investigated in Fall 2024 and Winter 2025.
